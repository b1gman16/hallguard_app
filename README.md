# HallGuard App

HallGuard is a Flutter mobile app for monitoring hallway safety events.

## Current app structure

- **Home**: live system status, recent alert summary, and camera health.
- **Alerts**: recent event feed with active and resolved filtering.

## Stack

- Flutter
- Firebase Core
- Cloud Firestore
- Firebase Messaging
- flutter_local_notifications

## Running locally

1. Install Flutter.
2. Run `flutter pub get`.
3. Configure Firebase for your target platform.
4. Launch with `flutter run`.
